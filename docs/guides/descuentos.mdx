Un descuento reduce el importe de una orden o compra. Puede restar un **monto fijo** o calcular un **porcentaje** sobre los items que definas.

El tipo del descuento determina dónde se usa. Elegilo antes de configurar su alcance.

## Elegir el tipo

<CardGroup cols={3}>
  <Card title="Liquidación" icon="file-invoice">
    Se asigna a clientes y se evalúa cuando generás sus órdenes en una liquidación.
  </Card>
  <Card title="Venta online" icon="cash-register">
    Queda disponible como descuento guardado para usar durante una venta en el Punto de Venta.
  </Card>
  <Card title="Eventos" icon="ticket">
    Funciona como un código que el comprador ingresa en el checkout del evento.
  </Card>
</CardGroup>

<Info>
  Un descuento de Venta online no funciona como cupón en el checkout público de Links de Pago ni en un evento. Cada tipo sirve en un solo canal.
</Info>

## Dónde está el stock

Sin stock **no se vende y el descuento no se aplica**. El número 0 no significa “ilimitado”.

| Qué | Dónde se carga | Qué corta cuando llega a 0 |
| --- | --- | --- |
| Producto de Venta online | **Items →** el producto | No entra al POS ni al link |
| Descuento de Venta online | **Items → Descuentos** (tipo Venta online) | No se puede usar en el POS |
| Entrada de eventos | **Items →** el tipo de entrada, o al crearla en el evento | No se vende en la página ni en el alta manual |
| Cupón de eventos | **Items → Descuentos** (tipo Eventos) | El código no se aplica en el checkout |
| Combo | Eventos → combo | No tiene stock propio. Descuenta el de cada tipo incluido |

En el listado de descuentos de eventos ves **usos confirmados**, no el stock. El stock está adentro del descuento: **Stock disponible**, **Editar** y **Ver historial de stock**.

## Crear un descuento

<Steps>
  <Step title="Abrí la pestaña Descuentos">
    Entrá a **Items → Descuentos** y presioná **Crear descuento**.
  </Step>
  <Step title="Elegí el tipo">
    Seleccioná Liquidación, Venta online o Entrada de eventos según el lugar donde se aplicará.
  </Step>
  <Step title="Definí el valor">
    Escribí un nombre y elegí entre monto fijo o porcentaje. Ingresá un valor mayor que cero.
  </Step>
  <Step title="Configurá el alcance">
    Indicá si aplica siempre o sobre todos los items, sólo algunos, o todos excepto los seleccionados.
  </Step>
  <Step title="Completá el canal">
    Configurá clientes y vigencia para Liquidación, stock para Venta online o código y restricciones para Eventos.
  </Step>
  <Step title="Guardá">
    Usá **Guardar** para dejarlo activo o **Guardar como borrador** para revisarlo después.
  </Step>
</Steps>

## Monto fijo o porcentaje

<Tabs>
  <Tab title="Monto fijo">
    Resta una suma definida. Podés hacerlo siempre o exigir que la orden incluya —o no incluya— determinados items.
  </Tab>
  <Tab title="Porcentaje">
    Calcula una proporción sobre todos los items, sólo algunos o todos excepto los seleccionados.
  </Tab>
</Tabs>

<Info>
  **Ejemplo:** una orden incluye Cuota escolar por $15.000 y Comedor por $3.000. Un 10% aplicado sólo a la cuota descuenta $1.500; el total queda en $16.500.
</Info>

## Descuento de Liquidación

Configurá su vigencia igual que la del concepto al que acompaña: pago único, mensual o anual. Para una duración definida, indicá la cantidad de ciclos.

Después seleccioná los clientes que reciben el beneficio. La liquidación evalúa los descuentos activos, asignados y vigentes junto con los items de cada perfil.

**Ejemplo:** “Beca académica 50%” aplicada a Cuota escolar 2027 para los clientes becados.

Podés asignar **más de una beca** a la misma cuota. Cada porcentaje se calcula sobre los cargos fijos, no sobre el resultado de la otra beca.

## Descuento de Venta online

Este tipo crea un beneficio guardado para el Punto de Venta. Dejalo activo y con stock disponible para poder aplicarlo durante una venta.

Podés exigir una cantidad mínima de productos y decidir qué productos cuentan para alcanzar ese mínimo. El alcance del descuento se configura por separado.

Los items de monto libre no cuentan para activar la condición de cantidad.

Primero definí el valor del descuento y la cantidad mínima que debe llevar la venta.

<img src="/docs/images/items-descuentos/descuento-cantidad-productos.png" alt="Descuento del 5 por ciento que exige dos prendas institucionales para activarse" />

Después elegí qué productos cuentan para alcanzar ese mínimo. En este ejemplo, son Buzo institucional 2027 y Remera institucional 2027.

<img src="/docs/images/items-descuentos/productos-descuento-cantidad.png" alt="Selector de productos del descuento con Buzo institucional 2027 y Remera institucional 2027 elegidos" />

Consultá [Descuentos en el Punto de Venta](/docs/guides/pos-descuentos) para ver descuentos guardados, manuales y combinaciones.

## Descuento de Eventos

Es un **código de cupón** para el checkout del evento, no un descuento del POS. Ejemplo: `PREVENTA10`. El código tiene que ser único en la organización.

Tiene **Stock disponible**. Cada vez que alguien aplica el código, Fint reserva 1. Si el stock es **0**, el cupón **no funciona**.

<Warning>
  Hoy **no descuenta combos**. El porcentaje se calcula solo sobre entradas sueltas. Si el carrito es solo combos, el descuento porcentual queda en cero. Un monto fijo sí se resta del total de la compra, aunque haya combos. No hay un interruptor en pantalla para aplicarlo a las entradas de un combo.
</Warning>

Además del alcance por tipos de entrada, podés pedir un total mínimo o máximo. Si es porcentual, también podés limitar el monto máximo descontado.

Después asociá el descuento **a ese evento**. Si no está en el evento, el código no aplica aunque tenga stock. El recorrido está en [Crear y publicar un evento](/docs/guides/eventos-crear-publicar#3-agregar-descuentos).

## Importar descuentos de Liquidación

Desde la pestaña Descuentos podés abrir **Importar Excel** y descargar el modelo actual. En la plantilla, un monto negativo se interpreta como descuento y sólo es válido para Liquidación.

La importación no configura clientes, condiciones ni códigos. Revisá cada descuento importado y completá esos datos antes de usarlo.
