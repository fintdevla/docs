title: 'Desarrolladores'
description: 'API keys y webhooks para conectar Fint con otro sistema'
---

**Configuración → Desarrolladores** es para un equipo técnico. El resto de las guías de esta sección no hace falta para cobrar.

<Tabs>
  <Tab title="API Keys">
    Una clave permite acceder a la API. **+ Crear API Key** pide un nombre. El secreto se muestra **una sola vez** en el modal **Importante**. Si no lo copiaste, hay que crear otra clave. El listado queda enmascarado.

    <img src="/docs/images/configuracion/desarrolladores-api-keys.png" alt="Pestaña API keys" />
  </Tab>
  <Tab title="Webhooks">
    Un webhook avisa a una URL cuando ocurre un evento en Fint.

    Al crearlo cargás la URL y los eventos. Hoy hay dos: **payment.created** (cuando un cobro queda acreditado) y **contact.status** (cuando cambia la condición o el estado del estudiante). Puede quedar **Activo** o **Pausado**. Fint no reenvía un evento fallido desde esta pantalla: mirá los registros en el detalle del webhook.

    <img src="/docs/images/configuracion/desarrolladores-webhooks.png" alt="Pestaña Webhooks" />
  </Tab>
</Tabs>
