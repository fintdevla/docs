---
title: 'Desarrolladores'
description: 'API keys y webhooks para conectar Fint con otro sistema'
---

**Configuración → Desarrolladores** es para un equipo técnico. El resto de las guías de esta sección no hace falta para cobrar.

<Tabs>
  <Tab title="API Keys">
    Una clave permite acceder a la API. Tiene un nombre y se muestra en parte oculta.

    **+ Crear API Key** pide un nombre.

    <img src="/docs/images/configuracion/desarrolladores-api-keys.png" alt="Pestaña API keys" />
  </Tab>
  <Tab title="Webhooks">
    Un webhook avisa a una URL cuando ocurre un evento en Fint.

    Al crearlo cargás la URL y los eventos. Puede quedar **Activo** o **Pausado**.

    <img src="/docs/images/configuracion/desarrolladores-webhooks.png" alt="Pestaña Webhooks" />
  </Tab>
</Tabs>
